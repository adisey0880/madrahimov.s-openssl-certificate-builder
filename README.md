# OpenSSL Certificate Builder

## Тема индивидуального проекта
"Создание сертификатов с помощью программы OpenSSL"

**Автор:** Мадрахимов Сарвар

## Цель проекта
Разработать кроссплатформенное веб-приложение, демонстрирующее процесс создания цифровых сертификатов с помощью программы OpenSSL. Проект является учебным программным модулем для изучения процессов генерации ключей, создания CSR-запросов, выпуска сертификатов и их проверки.

## Использованные технологии
- **HTML5** — семантическая структура веб-приложения.
- **CSS3** — адаптивное оформление интерфейса, светлая тема с акцентными цветами.
- **Vanilla JavaScript** — логика симулятора, генерация команд и обработка данных локально в браузере.
- *Без использования backend и сторонних библиотек.*

## Основные функции
- Генерация учебных OpenSSL-команд для RSA и EC.
- Создание учебного профиля закрытого ключа.
- Формирование CSR-профиля.
- Симуляция выпуска самоподписанного сертификата и сертификата от CA.
- Отображение структуры учебного сертификата и проверка срока действия.
- Копирование команд в буфер обмена.
- Фиксация результатов операций.

## Алгоритм создания сертификата
1. **Generate Private Key** (Генерация закрытого ключа)
2. **Create CSR** (Создание запроса на подпись)
3. **Submit CSR to CA** (Передача запроса в центр сертификации)
4. **Issue Certificate** (Выпуск сертификата)
5. **Verify Certificate** (Проверка сертификата)

## OpenSSL-команды
В проекте реализован справочник и генератор для следующих команд:
- `openssl genrsa ...`
- `openssl ecparam ...`
- `openssl req -new ...`
- `openssl req -x509 ...`
- `openssl x509 -req ...`
- `openssl verify ...`

## Инструкция пользователя
1. Откройте веб-приложение.
2. Перейдите в раздел "Генерация ключа" и выберите алгоритм.
3. Сформируйте команду генерации ключа.
4. Перейдите в раздел "Создание CSR", заполните данные организации (CN, O, C) и сформируйте команду.
5. Перейдите в раздел "Выпуск сертификата" и выберите тип (самоподписанный или через CA).
6. Перейдите в раздел "Проверка сертификата" для проверки структуры, срока действия и получения Fingerprint.
7. Используйте раздел "Результаты" для фиксации своих действий в отчёт.

## Как запустить локально
1. Убедитесь, что у вас установлен Node.js и npm.
2. Откройте терминал в папке проекта.
3. Выполните команду `npm install -g vercel` (если Vercel CLI не установлен).
4. Выполните команду `npm start` (запускает `vercel dev`).
5. Откройте локальный адрес (обычно `http://localhost:3000`) в браузере.

## Как развернуть на Vercel
1. Зарегистрируйтесь на [Vercel](https://vercel.com/) через GitHub.
2. Нажмите "Add New..." -> "Project".
3. Импортируйте ваш репозиторий GitHub.
4. Framework Preset можно оставить как `Other`, Vercel автоматически использует настройки из `vercel.json`.
5. Нажмите "Deploy".
