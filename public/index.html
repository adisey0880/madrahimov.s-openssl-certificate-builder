Постановка задачи

Задачей проекта является разработка веб-приложения, которое демонстрирует процесс создания цифровых сертификатов с использованием программы OpenSSL. Приложение должно формировать команды OpenSSL, показывать этапы генерации закрытого ключа, создания CSR-запроса, выпуска сертификата и проверки его параметров.

  • изучить назначение цифровых сертификатов;
  • рассмотреть роль OpenSSL при работе с сертификатами;
  • реализовать генератор команд для создания закрытого ключа;
  • реализовать генератор команд для создания CSR-запроса;
  • реализовать симуляцию выпуска сертификата;
  • реализовать отображение структуры сертификата;
  • реализовать проверку срока действия сертификата;
  • подготовить результаты работы программы и инструкцию пользователя.

Теория: цифровые сертификаты и OpenSSL

Цифровой сертификат

Связывает открытый ключ с владельцем и используется для подтверждения подлинности.

OpenSSL

Набор инструментов и библиотек для работы с криптографией, ключами, сертификатами и TLS/SSL.

Закрытый ключ

Используется для подписи CSR и должен храниться в строгом секрете.

CSR-запрос

Certificate Signing Request, запрос на выпуск сертификата, содержащий данные владельца и открытый ключ.

Центр сертификации

CA проверяет данные владельца и выпускает подписанный сертификат.

Самоподписанный сертификат

Сертификат, подписанный собственным закрытым ключом. Подходит для тестирования, но не является доверенным в публичных системах.

Практическое применение

HTTPS, корпоративные сервисы, VPN, электронная подпись, защищённые соединения, тестовые стенды.

Алгоритм создания сертификата

Создание сертификата начинается с генерации закрытого ключа. Далее на основе ключа формируется CSR-запрос, который передаётся в центр сертификации. После проверки данных CA выпускает сертификат, который можно проверить с помощью OpenSSL.

Инструкция пользователя

  1. Откройте веб-приложение.
  2. Перейдите в раздел "Генерация ключа".
  3. Выберите алгоритм RSA или EC.
  4. Сформируйте команду генерации ключа.
  5. Перейдите в раздел "Создание CSR".
  6. Заполните поля CN, O, C и Email.
  7. Сформируйте команду создания CSR.
  8. Перейдите в раздел "Выпуск сертификата".
  9. Выберите самоподписанный сертификат или сертификат через CA.
  10. Сформируйте команду выпуска сертификата.
  11. Перейдите в раздел "Проверка сертификата".
  12. Проверьте структуру сертификата, срок действия и fingerprint.
  13. Сохраните результаты для отчёта.
